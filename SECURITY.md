# Security Policy

Don't open a public GitHub issue for a security vulnerability. Email **gauravbisen999@gmail.com** with a description and, if possible, steps to reproduce.

This repo is exported from [CDIS Template](https://github.com/WorkGaurav1/cdis-engineering-template), which also covers `cdis-backend` and `cdis-deployment` — a vulnerability found here likely applies there too, worth mentioning in the report.
